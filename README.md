# 🎯 Number Guessing Game

## Description

A fun Python game where the computer randomly chooses a number and the player has to guess it.

---

## Features

- Three Difficulty Levels
- Random Number Generation
- Score System
- Multiple Rounds
- Input Validation

---

## Technologies

- Python 3

---

## Concepts Used

- random module
- while loop
- if-else statements
- Variables
- User Input
- Exception Handling

---

## How to Run

```bash
python guess_game.py
```
